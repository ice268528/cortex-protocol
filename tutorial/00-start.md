# 00 — 开始前：你不是来“学一套 Prompt”的

## 当前状态

你只有一句产品想法：

> 做一个内部 Feedback Inbox，让用户提交反馈，团队可以查看、分类并处理。

没有完整 PRD，没有 architecture，没有 Stage，没有 TODO。

## 这次练习的目标

不是让 ChatGPT 一次生成整套项目，而是让 Human 逐层形成自己的系统模型，然后把 accepted 结论变成 Repository state。

## YOUR JOB RIGHT NOW

```text
✓ 保留产品和系统的重要判断权
✓ 真正理解每一层设计
✓ 只在当前层的问题清零后接受文档
```

## DON'T DO THIS

```text
✗ “帮我把整个项目从产品到架构一次设计完”
✗ 把 ChatGPT 第一版输出直接当 truth
✗ 还没理解 Domain 就开始拆 implementation tasks
```
