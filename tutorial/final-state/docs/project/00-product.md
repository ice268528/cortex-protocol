# Feedback Inbox — Product Positioning & Boundaries

## Goal

让公司内部员工快速提交产品/流程反馈，并让 Support 团队在统一 Inbox 中处理。

## Users

- 已登录公司员工：提交反馈；
- Support 团队：查看、分类、推进状态。

## V1 Scope

- 员工提交 title + description；
- Support 查看全部 Feedback；
- Support 人工选择 category；
- Feedback 状态：`new / triaged / resolved`。

## Non-goals

- 匿名反馈；
- 自动 AI 分类；
- 邮件通知；
- 对外公开 Feedback portal。
