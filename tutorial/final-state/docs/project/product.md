# Product

> **Description:** Feedback Inbox 的 authoritative product intent。
> **Last Updated:** 2026-10-13

## North Star
让员工能低摩擦提交内部反馈，让 Support 有一个清晰可处理的反馈入口。

## Target User / Problem
员工缺少统一反馈入口；Support 缺少可追踪 Inbox。

## Core Experience
提交 → 查看 → 人工分类 → 处理。

## Product Principles
- M1 优先可靠、可理解的人工流程。
- 不因为 AI 能做而提前引入 AI。

## Initial Product Wedge
内部团队使用。

## Non-Goals
- M1 不做 AI auto-triage。
- M1 不做公开 customer portal。
