# Runtime and Services

本文件定义开发服务、Docker、临时进程和人工测试环境的运行规则。

## 1. 服务所有权
- Agent-owned：当前任务由 Coding Agent 启动。
- User-owned / pre-existing：用户或其他任务在当前工作开始前已运行。

只自动管理 Agent-owned 服务；不要关闭无法确认归属的已有服务。

## 2. 启动
启动服务前：
1. 确认需要哪些组件；
2. 检查是否已有等价服务运行；
3. 避免重复启动；
4. 使用 `CLAUDE.md` 或仓库文档定义的标准命令。

项目专属的端口、环境变量、Docker profile、数据库初始化、seed 和依赖启动顺序维护在本文件下方。

## 3. 人工测试
需要用户手动测试时：
- 保持必要的 Agent-owned 服务运行；
- 告诉用户访问入口和必要准备；
- 不在用户测试过程中关闭必要服务。

用户完成该轮测试后：
- 关闭当前任务启动且不再需要的前后端服务；
- 关闭仅为本轮验证启动的临时容器和辅助进程；
- 保留用户明确要求继续运行的服务。

## 4. 收尾
Work Item 收尾前检查并清理不再需要的 Agent-owned：
- 开发服务器；
- 临时 Docker 服务；
- watcher / 调试进程；
- 一次性辅助进程。

不要使用宽泛 kill 命令影响无关进程。
