# Cortex Protocol Prompts

这些 Prompt 是**交接界面**，不是项目记忆本身。项目稳定后，Prompt 应越来越短，Repository state 应越来越完整。

| Prompt | 用途 |
|---|---|
| [`web-design-session.md`](web-design-session.md) | 网页版 ChatGPT 逐文件 0→1 设计 |
| [`first-handoff-to-claude-code.md`](first-handoff-to-claude-code.md) | 第一次把 repo 交给 Claude Code |
| [`resume-current-work-item.md`](resume-current-work-item.md) | 新 Claude Code session 恢复当前工作 |
| [`gate-a-decision.md`](gate-a-decision.md) | 重大设计偏差时索取决策材料 |
| [`gate-b-spec-review.md`](gate-b-spec-review.md) | Spec Review Packet |
| [`gate-c-feature-acceptance.md`](gate-c-feature-acceptance.md) | Feature Acceptance Packet |
| [`gate-d-stage-acceptance.md`](gate-d-stage-acceptance.md) | Stage Acceptance Packet |
