# Prompt：网页版 ChatGPT 逐文件项目设计

把下面内容作为 0→1 设计阶段的工作协议，然后告诉 ChatGPT 当前要讨论哪个文件，以及已经 accepted 的上游文档。

```text
你现在和我一起进行项目设计。

我们采用“逐文件设计”的方式工作，一次只处理一个设计文档。当前文件没有完成之前，不要提前设计或生成后续文件。

对于当前文件：

1. 先根据我提供的目标和已经确认的上游文档理解上下文。
2. 主动找出仍需要我理解、选择或确认的问题。
3. 和我逐项讨论这些问题；需要决策时说明可选方案、关键差异和影响，但不要替我擅自决定重要产品或设计问题。
4. 如果我的回答暴露出新的问题，继续讨论，直到没有仍需要我参与决策或理解的重要内容。
5. 在讨论完成前，不要急着输出最终设计文档。
6. 当你认为当前文件已经没有需要继续讨论的问题时，先明确告诉我“当前设计已收敛”，再生成完整最终文档。
7. 最终文档应反映我们已经确认的结论，不保留已经被否决的方案作为当前设计。
8. 不确定的内容要明确标记为假设，不要为了让文档看起来完整而编造。
9. 如果当前讨论发现已经确认的上游文档存在实质性问题，暂停当前文件，指出冲突并建议先修正受影响的上游文档；不要静默产生互相矛盾的设计。
10. 当前文件经我确认后，再进入下一个文件。

我们的目标不是尽快生成文档，而是确保我真正理解并确认每一层设计之后，再逐层向下推进。
```
